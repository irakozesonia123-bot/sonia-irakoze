# Photos and screenshots still needed

Private working list. It is not linked from the site or included in any public page.
Updated 9 Nov 2026 against what is already in `public/images/`. Nothing below is already on file.

**How it works.** Save each file at the exact path (under `public/`), JPG about 1600 px wide (PNG for
screenshots and plots), then rebuild. Until a file exists, the live site shows the designed cover or
illustration in its place, never an empty box. Captions are already written in `src/content/`; each
one says what is shown and your part in it, so check it still matches the image you send.

**Your own work vs. reference images.** Only images of your own work go in these slots. If we later
add an outside image to explain a general idea (for example, what a CubeSat frame looks like), it will
be labeled "Reference image", credited, used only with reuse permission, and never shown as your
design or as evidence of a result. No reference images are on the site now.

Never send confidential CDOT or AGR material, internal data, or identifiable photos of workshop
participants (especially minors) without consent.
